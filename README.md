# 🎮 Game Menu

A small JavaScript project I made while learning the basics of JavaScript.

## Features

The program accepts three commands:

* `start` → Starts the program
* `stop` → Stops the program
* `premium` → Activates the premium feature
* Anything else → Shows an error message

## Concepts I practiced

* `const`
* Functions
* `if / else if / else`
* `prompt()`
* `console.log()`
* Function calls
* String comparison

## How to run

Open `script.js` in a JavaScript environment that supports `prompt()`, such as a browser console.

Then enter:

```text
start
stop
premium
```

## Example

